# JAKLOUD Spice King Dum Biryani

Full-stack project for JAKLOUD Spice King Dum Biryani.

## Project Structure

```
Jakcloud/
├── frontend/     # TanStack Start + React + Tailwind CSS client application
├── backend/      # Node.js + Express + TypeScript API server
├── package.json  # Root orchestration scripts
└── README.md
```

## Quick Start

### 1. Frontend
```bash
cd frontend
npm install
npm run dev
```
Accessible at: `http://localhost:5173` (or configured dev port)

### 2. Backend
```bash
cd backend
npm install
npm run dev
```
Accessible at: `http://localhost:5000`

### Root Scripts
From the root directory, you can also run:
- `npm run dev:frontend` - Start the frontend dev server
- `npm run dev:backend` - Start the backend dev server
- `npm run build` - Build both frontend and backend
